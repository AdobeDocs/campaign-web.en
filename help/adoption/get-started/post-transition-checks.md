# Checks and troubleshooting after the transition {#post-transition-checks}

After you transition from Campaign Standard to Campaign v8, some deliveries, workflows and landing pages may behave differently from what you expect. The table below lists symptoms reported by transitioned users, with the cause and what to do. For the full list of differences, see [Differences between Campaign Standard and Campaign v8](acs-v8-differences.md).

| Symptom | Cause and what to do | Learn more |
|---|---|---|
| Links in a delivery are direct URLs, and no click data is collected. | Tracking is disabled on the delivery or on the delivery template it is based on. Check that **Activate tracking** is enabled, in particular on the templates of your recurring deliveries. | [Tracking settings](../../v8/advanced-settings/delivery-settings.md#tracking-tab) |
| Recipients who unsubscribed through the "mailto" List-Unsubscribe method are not in quarantine. | This is expected. These recipients are not sent to quarantine. They are unsubscribed from the service associated with the delivery, or added to the denylist if the delivery has no service. To track these unsubscriptions, check the subscriptions of the service or the **No longer contact** section of the profile. | [Quarantines](https://experienceleague.adobe.com/en/docs/campaign/campaign-v8/send/failures/quarantines){target="_blank"} |
| A landing page does not save a value that is computed by a script or stored in a hidden field. | Landing pages created in the Campaign Web user interface do not support hidden input fields or custom JavaScript. Create the form as a web application in the client console instead. | [Landing pages](../../v8/landing-pages/get-started-lp.md) |
| **File transfer** does not find the file generated by a direct mail activity. | The outbound transition of a direct mail activity carries the targeted population, not the extraction file. Add a **Data extraction** activity, then the **File transfer** activity. | [Direct mail](https://experienceleague.adobe.com/en/docs/campaign/campaign-v8/send/direct-mail){target="_blank"} |
| Several waves of a delivery are sent together. | Waves are scheduled from the contact date of the delivery. If the delivery starts after the planned time of some waves, those waves are sent together instead of being spaced out. | [Send using waves](../../v8/advanced-settings/send-using-waves.md) |
| A file mask with characters after the asterisk finds no file in Azure Blob Storage. | Azure Blob Storage filters files by name prefix. Only a trailing asterisk is supported. | [Transfer external account](../../v8/administration/transfer-external-account.md) |
| A landing page or content block that uses custom JavaScript behaves differently. | Custom JavaScript is transformed during the migration, but validate and adjust it, in particular if it uses `queryDef`, Campaign JavaScript APIs, session writes, organizational unit handling or custom URL generation. | [Landing pages](../../v8/landing-pages/get-started-lp.md) |
| A REST API call returns a blank value, an error or an unexpected response. | Some database fields are dropped during the migration and return blank values. An empty PATCH returns 204, and a PATCH on location returns 500. A POST with a linked resource ignores the link or returns an error. An invalid PKEY returns 404. | [REST API limitations](acs-v8-differences.md#rest-api-limitations) |
| A stored PKEY no longer works in API calls. | PKEY values change after the migration. Do not store them outside Campaign. Form each call from the hrefs returned by the previous call. | [Key usage](acs-v8-differences.md#key-usage) |
| The time zone or `ccpaOptOut` is missing from a profile response. | These fields are returned only by `profileAndServicesExt/profile`, not by `profileAndServices/profile`. Call the extended endpoint. | [Profile time zone and ccpaOptOut](acs-v8-differences.md#profile-timezone) |
| A custom filter returns an error in a REST API call. | In Campaign v8, give the filter a name in the **Filter name in REST API** field, and use this name as is in the request, without the "by" prefix. | [Filtering](acs-v8-differences.md#rest-filtering) |
| A call that triggers a workflow external signal cannot build its request body. | The workflow GET API no longer returns the workflow variables. Build the parameters of the POST request body from your own knowledge of the workflow. | [Workflow external signals](acs-v8-differences.md#workflow-signals) |
| Access to the transactional APIs is denied. | Accessing transactional APIs from the execution instance requires a new product profile. Review the product profile mapping of your technical accounts. | [Product profile mapping](user-management-acs.md#product-profile-mapping-to-access-rest-apis) |
| A migrated audience shows only the latest value, or a file audience has no dimensions. | This is expected. A predefined filter takes only the latest value after the audience migration, and file-type audiences become List-type audiences without dimensions. | [Manage audiences](marketers.md#acs-gs-marketers-audiences) |
| The history of workflows executed in Campaign Standard is empty. | Historical logs of workflows executed in Campaign Standard are not migrated. Workflows executed in Campaign v8 have their own history and logs. | [Create a workflow](marketers.md#acs-gs-marketers-wf) |
| Some users can see or do more than before. | Users with the **Data Model** role but not the **Administration** role gain **Administration** access, and security groups with parallel organizational units can have broader access. Review the operator groups, named rights and folder permissions. | [User access management](user-management-acs.md) |
| A test profile marked as **Trap** does not receive the final send. | In Campaign v8, add a **Trap group** in the Audience settings of the delivery. | [Trap group](../../v8/audience/trap-group.md) |
| A recurring email has no aggregation period option. | This option is not available in Campaign v8. | [Channel activities](../../v8/workflows/activities/channels.md) |
| Dynamic reporting shows no data for a delivery. | Dynamic reporting covers email deliveries, campaigns with email deliveries, and transactional messages. | [Reporting](marketers.md#acs-gs-marketers-reporting) |
